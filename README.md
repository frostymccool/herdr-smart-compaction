# herdr-smart-compaction

Lets Claude Code sessions running in herdr panes compact their own context at natural stopping points when usage is 40-60%.

See [SKILL.md](SKILL.md) for how it works, install/uninstall, and tuning. Tests: `python3 -m pytest -q`.

Requires the `herdr` CLI, Claude Code and python3 3.9+. MIT licensed.
